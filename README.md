# eerraa-agent-docs

소스 우선 에이전트 문서 규약. 문서는 **코드에서 얻을 수 없는 요구·제약·이유**와 **작업의 첫 진입점**을 제공한다. 구현 설명이나 개발 일지를 복제하지 않는다.

| 작업 | 읽을 곳 |
|---|---|
| 일반 개발 | 작업 중인 레포의 로컬 `AGENTS.md`. 이 중앙 레포는 필독·빌드 의존성이 아니다 |
| 문서 규칙 확인 | [규약](AGENT_DOCS_CONVENTION.md) |
| 신규 채택·기존 문서 정비 | [채택 절차](ADOPTION.md) |
| 중앙 규약 자체 수정 | [중앙 작업 지침](AGENTS.md) |

## 배포와 채택

현재 규약 계열은 **v2**다. `main`은 유지보수 브랜치이며, 배포한 태그는 이동하지 않는다. 소비 레포는 검토한 태그 또는 commit에 고정하고 자기 진입 문서에 채택을 선언한다. 중앙 변경은 소비 레포에 자동 적용되지 않는다.

중앙 레포는 작성 표준만 소유한다. 소비 레포의 현재 상태·채택 현황·문서 개수·검사 결과를 수집하지 않는다. 규약 복제·자동 fetch·공유 실행 패키지·머신 전역 지침 변경은 필요 없다.

## 중앙 검증

Git checkout와 Python 3.11 이상이 필요하다. 추가 Python 패키지나 네트워크 접속 없이 실행한다.

```sh
python -X utf8 scripts/check.py
python -X utf8 -m unittest discover -s tests -v
```

[검사기](scripts/check.py)는 이 중앙 레포의 문서 링크·소유권 헤더·도달성·빈 입력·UTF-8·충돌 마커만 확인한다. [회귀시험](tests/test_check.py)이 정상·실패 입력을 검증하고 [CI](.github/workflows/docs.yml)가 같은 명령을 실행한다. 문장 의미, 요구 보존, 외부 링크의 가용성, 소비 레포의 규약 준수를 증명하지 않는다. 전체 CommonMark 검사기가 아니며 로컬 링크는 일반 inline Markdown 링크로 쓴다. 중앙의 계약·절차 문서는 `Genre:` / `Canonical for:`를 사용한다. 이는 중앙의 로컬 선택이지 소비 레포에 동일 형식을 강제하는 규칙이 아니다.

이력은 Git과 배포 태그에 남긴다. 실행 프롬프트·조사 보고·이행 장부는 활성 규약에 추가하지 않는다.
